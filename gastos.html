📧 Importar consumos desde Gmail
✅ Script de Gmail conectado. Tocá el botón para traer los consumos nuevos del banco.
⚙️ Todavía no configuraste la URL del script. Seguí los pasos de abajo una sola vez y después podés actualizar los consumos con un botón desde cualquier dispositivo.
Pasos para configurar (solo la primera vez):
1. Abrí script.google.com en cualquier navegador
2. Creá un proyecto nuevo (botón + Nuevo proyecto)
3. Borrá todo el código que aparece y pegá el contenido de codigo-gmail.gs
4. Guardá (Ctrl+S) y hacé clic en Implementar → Nueva implementación
5. Tipo: Aplicación web · Ejecutar como: Yo · Quién puede acceder: Cualquier usuario
6. Copiá la URL que te da y pegala en ⚙️ Config → URL Apps Script
▾ Alternativa: pegar JSON manualmente
2 · Revisá y asigná cuotas

Revisá cada consumo, ajustá las cuotas si corresponde, y apretá Importar.
